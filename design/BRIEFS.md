# CONTRAIL — screen briefs (one section per artboard)

Every screen: 1600 × 900, chrome from SPEC §4 (except InFlight), tokens/components from SPEC §1 and §5,
data from SPEC §9–10. "Panel" = SPEC §5 card. Heights given are targets so everything fits without clipping;
the content area between the bars is 780 px tall (64 top bar + 56 bottom bar), 1520 px wide inside the 40-px page padding,
minus the main's 24-px top/bottom padding → ~732 px of usable height including the page header.
Every list/grid that would overflow is drawn cut off cleanly at its bottom edge with the scrollbar indicator.
Draw exactly ONE selected state per group. Keep copy terse and aviation-literate.
